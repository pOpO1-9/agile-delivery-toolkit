# Agile Delivery Toolkit

Kit FR pour cadrer une livraison : kickoff, backlog, sprints, syncs client, risques.

Fait pour des rôles **chef de projet IT junior**, **Scrum Master** ou **coordination de delivery**.

## Ouvrir le kit

- En ligne : https://popo1-9.github.io/agile-delivery-toolkit/
- Sur Windows : double-cliquer `Ouvrir-le-kit.bat` (Node.js requis)

## Contenu

- `templates/` — 9 documents prêts à remplir
- `guides/` — playbook client + cérémonies Scrum
- `examples/` — étude de cas + sprint type
- `web/` — interface pour lire / remplir / télécharger

## Usage rapide

1. Copier les templates dans Notion, Confluence ou le repo projet
2. Kickoff + RACI avant le premier sprint
3. Backlog et risques tenus à jour
4. Statut court pour le sponsor
5. Revue + rétro en fin de sprint
